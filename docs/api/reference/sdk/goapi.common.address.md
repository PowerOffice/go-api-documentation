
Address
================

Address representing a physical location.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Common.Address.Id.md)|Gets or sets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[Address1](GoApi.Common.Address.Address1.md)|Gets or sets the first address line. This is usually used for street name or postal box.
[Address2](GoApi.Common.Address.Address2.md)|Gets or sets the second address line. Used for additional specifications of the address.
[Address3](GoApi.Common.Address.Address3.md)|OBSOLETE - Gets or sets the third address line. This property is no longer in use and will be removed on a later date.
[City](GoApi.Common.Address.City.md)|Gets or sets the city.
[CountryCode](GoApi.Common.Address.CountryCode.md)|Gets or sets the ISO 3166-1 alfa-2 country code (Two characters)
[ExternalCode](GoApi.Common.Address.ExternalCode.md)|Get or sets the external code - can be used to reference the address in the external system
[IsPrimary](GoApi.Common.Address.IsPrimary.md)|Flag indicating whether or not this address is the primary delivery address. Primary delivery address will be suggested as the delivery address when creating new invoices.
[LastChanged](GoApi.Common.Address.LastChanged.md)|Gets or sets the last changed date (DateTimeOffset).
[ZipCode](GoApi.Common.Address.ZipCode.md)|Gets or sets the zip code (postal code).
