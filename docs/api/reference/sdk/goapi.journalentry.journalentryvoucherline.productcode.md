
JournalEntryVoucherLine.ProductCode
================
**Namespace:** GoApi.JournalEntry

Gets or sets the productcode for the line. The [Product](GoApi.Products.Product.md) must exist in Go in order to be set, and the client need to have product activated in the journal entry settings

### Syntax
```csharp
	public string ProductCode { get; set; }
```

### Type

string
