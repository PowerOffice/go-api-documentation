
TimeTrackingEntry.IsInvoiced
================
**Namespace:** GoApi.TimeTracking

Gets or sets a value indicating whether this instance is invoiced. Time tracking entries that have been transferred to invoice can no longer be edited.

### Syntax
```csharp
	public Nullable<System.bool> IsInvoiced { get; set; }
```

### Type

System.Nullable&lt;System.bool&gt;
