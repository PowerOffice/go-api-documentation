
AuthorizationSettings.EndPointHost
================
**Namespace:** GoApi.Core

The endpoint to use for service calls. If omitted, will fall back to GoApi.Core.Global.Settings.Mode . It is highly recommended to explicitly specify the endpoint mode.

### Syntax
```csharp
	public Nullable<GoApi.Core.Global.Host> EndPointHost { get; set; }
```
