
VoucherLineBase.DepartmentCode
================
**Namespace:** GoApi.Voucher

Gets or sets the code of the [Department](GoApi.Dimension.Department.md) .     If set to "-1", this line will not inherit the department set on the voucher level, and no department will be posted to Go for this line

### Syntax
```csharp
	public string DepartmentCode { get; set; }
```

### Type

string
