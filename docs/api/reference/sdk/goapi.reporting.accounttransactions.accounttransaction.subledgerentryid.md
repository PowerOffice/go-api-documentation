
AccountTransaction.SubLedgerEntryId
================
**Namespace:** GoApi.Reporting.AccountTransactions

Gets the sub ledger entry id. If this AccountTransaction is on a sub ledger account this will be the value of the sub ledger entry related to this transaction.

### Syntax
```csharp
	public Nullable<System.long> SubLedgerEntryId { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
