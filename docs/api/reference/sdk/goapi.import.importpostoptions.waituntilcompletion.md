
ImportPostOptions.WaitUntilCompletion
================
**Namespace:** GoApi.Import

Gets or sets a value indicating whether to wait until post has been completed, or return immediately.     If WaitTimeout has been set the wait will throw an exception when the [WaitTimeout] amount of time has passed.

### Syntax
```csharp
	public bool WaitUntilCompletion { get; set; }
```

### Type

bool
