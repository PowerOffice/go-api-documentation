
FactoringService
================

Factoring service used by factoring agencies that have an integration with PowerOffice Go.     Provides methods to get FactoringSetting , get list of [FactoringInvoiceDetails](GoApi.Factoring.FactoringInvoiceDetails.md) ready to be taken by the factoring company, get invoice details in EHF-like format, push back the invoice PDF generated by factoring company and set factoring status of the invoice.

### Methods
Name | Description
:----|:------------
[Delivered(FactoringInvoiceDetailsDeliveredRequest request)](GoApi.Factoring.FactoringService.Delivered_FactoringInvoiceDetailsDeliveredRequest_request_.md)|Adds an history entry on the [FactoringInvoiceDetails](GoApi.Factoring.FactoringInvoiceDetails.md) that an invoice has been delivered with an optional file and comment.      Calling this will set GoApi.Factoring.FactoringInvoiceDetails.IsDelivered to true.     Can only be called on invoices with GoApi.Factoring.FactoringInvoiceStatus.Active .
[GetAvailableInvoices()](GoApi.Factoring.FactoringService.GetAvailableInvoices__.md)|Gets the available [FactoringInvoiceDetails](GoApi.Factoring.FactoringInvoiceDetails.md) . that is not delivered, filtered by oData query.
[GetInvoiceEhf(Guid invoiceId)](GoApi.Factoring.FactoringService.GetInvoiceEhf_Guid_invoiceId_.md)|Get the ehf xml document for a [FactoringInvoiceDetails](GoApi.Factoring.FactoringInvoiceDetails.md) invoice by it's Id as Stream.
[GetInvoicesDelivered()](GoApi.Factoring.FactoringService.GetInvoicesDelivered__.md)|Gets a list of [FactoringInvoiceDetails](GoApi.Factoring.FactoringInvoiceDetails.md) delivered by actual API user filtered by a oData query.
[UpdateFactoringInvoiceStatus(FactoringInvoiceStatusRequest request)](GoApi.Factoring.FactoringService.UpdateFactoringInvoiceStatus_FactoringInvoiceStatusRequest_request_.md)|Updates the factoring status on the invoice with a specified [FactoringInvoiceStatus](GoApi.Factoring.FactoringInvoiceStatus.md) .     Cannot be called before the invoice is delivered through the GoApi.Factoring.FactoringService.Delivered(GoApi.Factoring.FactoringInvoiceDetailsDeliveredRequest) method.
