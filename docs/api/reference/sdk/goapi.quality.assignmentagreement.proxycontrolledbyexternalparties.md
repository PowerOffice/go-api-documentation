
AssignmentAgreement.ProxyControlledByExternalParties
================
**Namespace:** GoApi.Quality

Gets or sets the ProxyControlledByExternalParties. If set to true, the value from ProxyControlledByExternalName must be set.     If set to false, ProxyControlledById must be set.     This represents the controlled by external parties found under Customer Initiatives in the Assignment Assessment tab.

### Syntax
```csharp
	public bool ProxyControlledByExternalParties { get; set; }
```
