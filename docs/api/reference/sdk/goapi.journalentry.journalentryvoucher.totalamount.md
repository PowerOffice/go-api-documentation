
JournalEntryVoucher.TotalAmount
================
**Namespace:** GoApi.JournalEntry

The total amount of this voucher. Can be used on with VoucherType GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice , GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote and GoApi.JournalEntry.JournalEntryVoucherType.Expense .     This is the total amount set on the head of the Voucher and the amount that is posted on the sub ledger account.

```csharp
	public Nullable<System.decimal> TotalAmount { get; set; }
```
