
InternationalPaymentFeeDistribution
================

Enum that describes different ways of distributing the fees when making an international bank wire transfer

### Fields
Name |Value | Description
:----|:-----|:-----------
Shared|0|The fees are shared between the sender and the receiver.
Sender|1|The sender pays all fees.
Receiver|2|The receiver pays all fees.
