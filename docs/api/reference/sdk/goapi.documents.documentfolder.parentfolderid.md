
DocumentFolder.ParentFolderId
================
**Namespace:** GoApi.Documents

The id of the parent folder.         New folders will be added to folder specified by parentFolderId. If no parentFolderId is specified, folder will be added to "Shared documents"

### Syntax
```csharp
	public Nullable<System.long> ParentFolderId { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
