
TimeTrackingEntry.HourType
================
**Namespace:** GoApi.TimeTracking

Gets or sets the description of the [HourType](GoApi.TimeTracking.HourType.md) . If provided, there must exist an HourType with the same description as this property. If no value is set this time tracking entry will default to ordinary time.

### Syntax
```csharp
	public string HourType { get; set; }
```

### Type

string
