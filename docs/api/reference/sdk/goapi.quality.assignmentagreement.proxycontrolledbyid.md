
AssignmentAgreement.ProxyControlledById
================
**Namespace:** GoApi.Quality

Gets or sets ProxyControlledById. This is an employee id. Used if ProxyControlledByExternalParties is set to false. Represents the controlled by found under Customer Initiatives in the Assignment Assessment tab.

### Syntax
```csharp
	public Nullable<System.long> ProxyControlledById { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
