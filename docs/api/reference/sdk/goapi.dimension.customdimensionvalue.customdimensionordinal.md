
CustomDimensionValue.CustomDimensionOrdinal
================
**Namespace:** GoApi.Dimension

Gets or sets the custom dimension ordinal.      When creating a new CustomDimensionValue either CustomDimensionDefinitionCode or CustomDimensionOrdinal must be provided and CustomDimensionDefinitionCode takes precedence when both are provided

### Syntax
```csharp
	public int CustomDimensionOrdinal { get; set; }
```

### Type

int
