
AssignmentAgreement.ProxyControlledByCode
================
**Namespace:** GoApi.Quality

Gets or sets ProxyControlledByCode. This is an employee code. Used if ProxyControlledByExternalParties is set to false. Represents the controlled by found under Customer Initiatives in the Assignment Assessment tab.

### Syntax
```csharp
	public Nullable<System.long> ProxyControlledByCode { get; set; }
```
