
public TProperty Get(string propertyName)
=======
**Namespace:** GoApi.Core.OData

Gets the strongly-typed value of the named property. This method can be used in OData queries as long as &lt;paramref name="propertyName"&gt;&lt;/paramref&gt; is a constant or local variable capture

### Syntax
```csharp
	public TProperty Get(string propertyName)
```

### Parameters
Name | Type | Description
:----|:-----|:------------
propertyName|string|the property name


### Returns
Type | Description
:----|:------------
[TProperty](GoApi.Core.OData.TProperty.md)|the property value
