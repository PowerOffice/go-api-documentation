
OutgoingInvoice.SentDate
================
**Namespace:** GoApi.Invoices

Gets the date the invoice was sent in Go. Only available for invoices sent from Go. Blank if the invoice was posted to Go using an import of the voucher.

### Syntax
```csharp
	public Nullable<System.DateTimeOffset> SentDate { get; internal set; }
```

### Type

System.Nullable&lt;System.DateTimeOffset&gt;
