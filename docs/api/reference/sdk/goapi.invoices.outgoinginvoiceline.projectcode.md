
OutgoingInvoiceLine.ProjectCode
================
**Namespace:** GoApi.Invoices

Gets or sets the code of the [Project](GoApi.Projects.Project.md) this line is for.         By default the ProjectCode in the head (OutgoingInvoice) will be inherited and used when this is null.         Use "-1" to set "No project".

### Syntax
```csharp
	public string ProjectCode { get; set; }
```

### Type

string
