
JournalEntryVoucher.SubmitForApprovalErrorMessage
================
**Namespace:** GoApi.JournalEntry

Gets an error message/reason for failing to submit the voucher for approval. Will only contain a value in the response when saving a new JournalEntryVoucher with the flag GoApi.JournalEntry.JournalEntryVoucher.SubmitForApproval and the submission failed.

### Syntax
```csharp
	public string SubmitForApprovalErrorMessage { get; internal set; }
```

### Type

string
