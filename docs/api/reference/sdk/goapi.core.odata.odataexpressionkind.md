
ODataExpressionKind
================

Represents the different types of OData expressions. Compare to System.Linq.Expressions.ExpressionType in      LINQ expressions

### Fields
Name |Value | Description
:----|:-----|:-----------
Query|0|Represents an entire query
BinaryOp|1|Represents a binary operation like adition
UnaryOp|2|Represents a unary operation like "not"
Call|3|Represents a method call
Constant|4|Represents a literal value
MemberAccess|5|Represents a simple or navigation property access
Convert|6|Represents a cast
SortKey|7|Represents a value to sort by along with a sort direction
SelectColumn|8|Represents a projected "column"
