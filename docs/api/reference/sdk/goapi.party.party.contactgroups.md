
Party.ContactGroups
================
**Namespace:** GoApi.Party

Gets or sets the contact groups. This collection will contain the names of all the [ContactGroup](GoApi.Party.ContactGroup.md) the party is associated with.     If the collection is provided a contact group that does not exist, the contact group will be created when saving.

### Syntax
```csharp
	public IEnumerable<System.string> ContactGroups { get; set; }
```

### Type

System.Collections.Generic.IEnumerable&lt;System.string&gt;
