
DebtCollectionInvoiceMatch.CreatedFromImportId
================
**Namespace:** GoApi.DebtCollection

Gets the identifier of the [Import](GoApi.Import.Import.md) that created this voucher. If this voucher is not created from an [Import](GoApi.Import.Import.md) this value will be null.

### Syntax
```csharp
	public Nullable<System.Guid> CreatedFromImportId { get; internal set; }
```
