
JournalEntryVoucher.Description
================
**Namespace:** GoApi.JournalEntry

Description of the Voucher. Can be used to describe the voucher and is set on the head. Can be used on all voucher types EXCEPT GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice , GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote .

### Syntax
```csharp
	public string Description { get; set; }
```

### Type

string
