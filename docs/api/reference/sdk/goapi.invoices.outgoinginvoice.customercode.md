
OutgoingInvoice.CustomerCode
================
**Namespace:** GoApi.Invoices

Gets or sets the code of the [Customer](GoApi.Party.Customer.md) that this invoice should be delivered to.         It is not possible to set GoApi.Invoices.OutgoingInvoice.ContactGroupId and CustomerCode on the same invoice.

### Syntax
```csharp
	public Nullable<System.long> CustomerCode { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
