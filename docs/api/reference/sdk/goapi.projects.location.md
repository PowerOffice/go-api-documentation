
Location
================

Location representing a location where this client conducts business.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Projects.Location.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[Code](GoApi.Projects.Location.Code.md)|Gets or sets the code of the location. This is an unique identificator.
[IsActive](GoApi.Projects.Location.IsActive.md)|Gets or sets a value indicating whether this location is active. Defaults to true.
[Name](GoApi.Projects.Location.Name.md)|Gets or sets the name of the location.
