
ImportLine.CustomerCode
================
**Namespace:** GoApi.Import

Gets or sets code of the [Customer](GoApi.Party.Customer.md) to post on. GoApi.Import.ImportLine.AccountNumber will be ignored on entries posted on a sub ledger account.

### Syntax
```csharp
	public Nullable<System.long> CustomerCode { get; set; }
```

### Type
