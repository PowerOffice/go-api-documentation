
SalesOrder.RecurringInfo
================
**Namespace:** GoApi.SalesOrders

Gets or sets the recurring information ( [SalesOrderRecurringInfo](GoApi.SalesOrders.SalesOrderRecurringInfo.md) ). Should only be provided if you want to create this sales order as an         Recurring Invoice (repeating). Defaults to *null* .

### Syntax
```csharp
	public SalesOrderRecurringInfo RecurringInfo { get; set; }
```
