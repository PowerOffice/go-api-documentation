
Department.CreatedFromImportJournalId
================
**Namespace:** GoApi.Dimension

Gets the created from import journal identifier. If the department was created from an import, this property will contain the ID of the [Import](GoApi.Import.Import.md) that created this account.

### Syntax
```csharp
	public Nullable<System.Guid> CreatedFromImportJournalId { get; internal set; }
```

### Type

System.Nullable&lt;System.Guid&gt;
