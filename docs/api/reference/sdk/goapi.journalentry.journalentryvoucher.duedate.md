
JournalEntryVoucher.DueDate
================
**Namespace:** GoApi.JournalEntry

The due date on the head of the voucher. Can be used on vouchers with VoucherType GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice , GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote and GoApi.JournalEntry.JournalEntryVoucherType.Expense .

### Syntax
```csharp
	public Nullable<System.DateTime> DueDate { get; set; }
```

### Type
