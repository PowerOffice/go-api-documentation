
FactoringInvoiceDetailsDeliveredRequest
================

Request to be used when updating that a [FactoringInvoiceDetails](GoApi.Factoring.FactoringInvoiceDetails.md) has been delivered to a customer by an external third party.


### Properties
Name | Description
:----|:------------
[Comment](GoApi.Factoring.FactoringInvoiceDetailsDeliveredRequest.Comment.md)|Comment that will be displayed as a history entry on the voucher.
[FactoringInvoiceId](GoApi.Factoring.FactoringInvoiceDetailsDeliveredRequest.FactoringInvoiceId.md)|The id of the invoice or credit note that has been delivered.
[File](GoApi.Factoring.FactoringInvoiceDetailsDeliveredRequest.File.md)|[FactoringInvoiceDocumentationFile](GoApi.Factoring.FactoringInvoiceDocumentationFile.md) containing the documentation of the voucher that has been sent, this can be downloaded by a user through the history entry on the voucher in Go.
[InvoiceCid](GoApi.Factoring.FactoringInvoiceDetailsDeliveredRequest.InvoiceCid.md)|The CID of the invoice created by factoring company. (Norwegian: KID)
