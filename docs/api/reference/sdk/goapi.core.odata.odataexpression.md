
ODataExpression
================

Represents a node in the OData "language". This class also contains static factories     for specific expression types, much like System.Linq.Expressions.Expression


### Properties
Name | Description
:----|:------------
[ClrType](GoApi.Core.OData.ODataExpression.ClrType.md)|the .NET type of the expression
[Kind](GoApi.Core.OData.ODataExpression.Kind.md)|the expression kind
[Type](GoApi.Core.OData.ODataExpression.Type.md)|the odata type of the expression


### Methods
Name | Description
:----|:------------
[ToString()](GoApi.Core.OData.ODataExpression.ToString__.md)|Returns the OData expression language text for the expression
