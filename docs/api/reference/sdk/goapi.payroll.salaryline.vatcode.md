
SalaryLine.VatCode
================
**Namespace:** GoApi.Payroll

Gets or sets code of the [VatCode](GoApi.Dimension.VatCode.md) to be used on the salary line.     Can be specified for instance when the PayItem on the salary line is of type GoApi.Payroll.PayItemProcessingType.ExpenseRefund to specify the Vat Code.

### Syntax
```csharp
	public string VatCode { get; set; }
```

### Type

string
