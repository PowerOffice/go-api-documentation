
Go.DeliveryTerms
================
**Namespace:** GoApi

Service used to create, read, update and delete [DeliveryTerm](GoApi.Invoices.DeliveryTerm.md) available on the client.     If a delivery term is default, it cannot be deleted. In this case another delivery term must be set to default before delete can be done.

### Syntax
```csharp
	public DeliveryTermsService DeliveryTerms { get; }
```

### Type

[DeliveryTermsService](GoApi.Invoices.DeliveryTermsService.md)
