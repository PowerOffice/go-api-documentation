
OutgoingInvoice.ProjectCode
================
**Namespace:** GoApi.Invoices

Gets or sets the code of the [Project](GoApi.Projects.Project.md) this invoice is for.         This code will be inherited on all OutgoingInvoiceLines unless "-1" (no project) is specified.

### Syntax
```csharp
	public string ProjectCode { get; set; }
```

### Type

string
