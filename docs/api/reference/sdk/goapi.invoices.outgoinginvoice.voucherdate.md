
OutgoingInvoice.VoucherDate
================
**Namespace:** GoApi.Invoices

Gets the voucher date. This is the date when the invoice was sent from PowerOffice Go and will only have a value on sent invoices.

### Syntax
```csharp
	public Nullable<System.DateTime> VoucherDate { get; internal set; }
```

### Type

System.Nullable&lt;System.DateTime&gt;
