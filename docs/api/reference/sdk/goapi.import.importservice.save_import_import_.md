
public override Import Save(Import import)
=======
**Namespace:** GoApi.Import

Saves the provided [Import](GoApi.Import.Import.md) .         This will upload the import to PowerOffice Go and users might manually post the imports there or the integration can do this through the GoApi.Import.ImportService.Post(GoApi.Import.Import,GoApi.Import.ImportPostOptions) method.

### Syntax
```csharp
	public override Import Save(Import import)
```

### Parameters
Name | Type | Description
:----|:-----|:------------
import|[Import](GoApi.Import.Import.md)|The import.


### Returns
Type | Description
:----|:------------
[Import](GoApi.Import.Import.md)|Import.
