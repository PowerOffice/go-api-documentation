
BankTransfer.IsOnHold
================
**Namespace:** GoApi.Bank

Gets or sets a value indicating whether this instance is on hold. On hold payments must be manually set to a specific payment date before authorizing by a user in PowerOffice Go.

### Syntax
```csharp
	public Nullable<System.bool> IsOnHold { get; set; }
```

### Type

System.Nullable&lt;System.bool&gt;
