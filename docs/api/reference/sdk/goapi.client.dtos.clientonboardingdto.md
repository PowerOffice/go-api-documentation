
ClientOnboardingDto
================

Response from PowerOffice Go after on-boarding a new client integration.


### Properties
Name | Description
:----|:------------
[ClientKey](GoApi.Client.Dtos.ClientOnboardingDto.ClientKey.md)|The generated client key of the client integration. Can be used alongside the application key to authenticate with the client.
[ClientName](GoApi.Client.Dtos.ClientOnboardingDto.ClientName.md)|The name of the client that has added the integration.
[ClientOrganizationNumber](GoApi.Client.Dtos.ClientOnboardingDto.ClientOrganizationNumber.md)|The organization number of the client that has added the integration.
[Success](GoApi.Client.Dtos.ClientOnboardingDto.Success.md)|Flag indicating whether the on-boarding was successful or not.
[UserEmail](GoApi.Client.Dtos.ClientOnboardingDto.UserEmail.md)|The email of the user that approved the integration.
