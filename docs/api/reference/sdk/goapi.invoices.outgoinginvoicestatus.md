
OutgoingInvoiceStatus
================

Enum OutgoingInvoiceStatus representing the different statuses a outgoing invoice ( [OutgoingInvoice](GoApi.Invoices.OutgoingInvoice.md) / [OutgoingInvoiceListItem](GoApi.Invoices.OutgoingInvoiceListItem.md) ) can have.

### Fields
Name |Value | Description
:----|:-----|:-----------
Draft|0|Invoice is in draft status and can be edited.
Approved|1|Invoice has been approved.
Sent|2|Invoice has been delivered to the customer.
Paid|3|Invoice has been paid fully by the customer.
Archived|4|Invoice has been archived.
