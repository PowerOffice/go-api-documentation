
ProjectTeamMember
================

Project team member representing a [Employee](GoApi.Party.Employee.md) that is a team member on a [Project](GoApi.Projects.Project.md) .


### Properties
Name | Description
:----|:------------
[Id](GoApi.Projects.ProjectTeamMember.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[BudgetHours](GoApi.Projects.ProjectTeamMember.BudgetHours.md)|Gets or sets the amount of budgeted hours for the employee on this project.
[EmployeeCode](GoApi.Projects.ProjectTeamMember.EmployeeCode.md)|Gets or sets the code of the [Employee](GoApi.Party.Employee.md) .
[HourlyRate](GoApi.Projects.ProjectTeamMember.HourlyRate.md)|Gets or sets the hourly rate for the employee on this project.
[ProjectCode](GoApi.Projects.ProjectTeamMember.ProjectCode.md)|Gets the code of the [Project](GoApi.Projects.Project.md) .
