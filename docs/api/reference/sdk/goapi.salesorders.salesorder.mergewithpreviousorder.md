
SalesOrder.MergeWithPreviousOrder
================
**Namespace:** GoApi.SalesOrders

Gets or sets a value indicating whether [merge with previous order]. If set to *true* , this SalesOrder will be         merged with another SalesOrder to the same customer if any. Defaults to *false* .

### Syntax
```csharp
	public bool MergeWithPreviousOrder { get; set; }
```

### Type

bool
