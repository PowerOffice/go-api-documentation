
Accrual.NumOfMonths
================
**Namespace:** GoApi.Invoices

Used by recurring invoice to specify the number of months the invoice should be accrued over.     This property will only be used if the accrual is on a line that is on a [RecurringInvoice](GoApi.Invoices.RecurringInvoice.md)

### Syntax
```csharp
	public Nullable<System.int> NumOfMonths { get; set; }
```

### Type

System.Nullable&lt;System.int&gt;
