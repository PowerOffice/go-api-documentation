
JournalEntryVoucher.ContractNo
================
**Namespace:** GoApi.JournalEntry

Field representing the contract number on the voucher. Can be used on vouchers of type GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice and GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote .

	public string ContractNo { get; set; }
