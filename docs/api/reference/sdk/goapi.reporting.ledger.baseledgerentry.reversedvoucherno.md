
BaseLedgerEntry.ReversedVoucherNo
================
**Namespace:** GoApi.Reporting.Ledger

Gets the voucher number of the original voucher that has been reversed by thin voucher.     This property is only available for reversal vouchers (type 99), and link the reversal voucher to the original voucher that has been reversed in Go.

### Syntax
```csharp
	public Nullable<System.long> ReversedVoucherNo { get; internal set; }
```

### Type

System.Nullable&lt;System.long&gt;
