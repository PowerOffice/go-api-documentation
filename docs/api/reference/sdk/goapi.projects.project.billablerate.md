
Project.BillableRate
================
**Namespace:** GoApi.Projects

Gets or sets the project billable rate. The GoApi.Projects.Project.BillingMethod must Time or Time and expense, and GoApi.Projects.Project.BillingHourlyRateSpecification must be Project when using this value.

### Syntax
```csharp
	public Nullable<System.decimal> BillableRate { get; set; }
```
