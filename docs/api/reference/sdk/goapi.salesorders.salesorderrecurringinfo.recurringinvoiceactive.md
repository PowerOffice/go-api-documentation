
SalesOrderRecurringInfo.RecurringInvoiceActive
================
**Namespace:** GoApi.SalesOrders

Gets or sets a value indicating whether [recurring invoice active]. Must be set to true to create the [SalesOrder](GoApi.SalesOrders.SalesOrder.md) as a recurring invoice.
