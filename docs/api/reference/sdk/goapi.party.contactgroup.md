
ContactGroup
================

ContactGroup representing a group of parties. A group can contain both [Customer](GoApi.Party.Customer.md) , [Supplier](GoApi.Party.Supplier.md) and [Employee](GoApi.Party.Employee.md) .


### Properties
Name | Description
:----|:------------
[Id](GoApi.Party.ContactGroup.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[SendInvoicesToGroup](GoApi.Party.ContactGroup.SendInvoicesToGroup.md)|Gets or sets a value indicating whether it is allowed to send a group invoice to the [Customer](GoApi.Party.Customer.md) in the group.
[Title](GoApi.Party.ContactGroup.Title.md)|Gets or sets the title of the contact group. This title is unique per client (ignore case).
