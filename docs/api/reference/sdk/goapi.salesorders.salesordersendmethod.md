
SalesOrderSendMethod
================

Enum RecurringSendMethod. Describes what happens to a recurring invoice when the invoice date is reached.

### Fields
Name |Value | Description
:----|:-----|:-----------
Confirm|0|Invoice will be confirmed, and must manually be sent afterwards.
Send|1|Invoice will be sent automatically to customer.
Draft|2|Invoice will be saved as an invoice draft only
