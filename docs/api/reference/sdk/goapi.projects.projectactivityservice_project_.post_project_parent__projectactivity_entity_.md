
public virtual ProjectActivity Post(Project parent, ProjectActivity entity)
=======
**Namespace:** GoApi.Projects

Adds the activity as a activity to the project. The activity has be be created through the activity service before         calling this method.

### Syntax
```csharp
	public virtual ProjectActivity Post(Project parent, ProjectActivity entity)
```

### Parameters
Name | Type | Description
:----|:-----|:------------
parent|[Project](GoApi.Projects.Project.md)|The project.
entity|[ProjectActivity](GoApi.Projects.ProjectActivity.md)|The activity.


### Returns
Type | Description
:----|:------------
[ProjectActivity](GoApi.Projects.ProjectActivity.md)|Activity.
