
BankTransfer.ReceivableBankAccountCode
================
**Namespace:** GoApi.Bank

Gets or sets the receivable bank account (bank account transferred to). This property is required when creating new bank transfers.     If the transfer is international it's recommended to use IBAN number instead of bank account number.

### Syntax
```csharp
	public string ReceivableBankAccountCode { get; set; }
```

### Type

string
