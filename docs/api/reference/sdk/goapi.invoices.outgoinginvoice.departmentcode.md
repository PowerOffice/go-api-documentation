
OutgoingInvoice.DepartmentCode
================
**Namespace:** GoApi.Invoices

Gets or sets code of the [Department](GoApi.Dimension.Department.md) this invoice is for.         This code will be inherited on all OutgoingInvoiceLines unless "-1" (no department) is specified.

### Syntax
```csharp
	public string DepartmentCode { get; set; }
```

### Type

string
