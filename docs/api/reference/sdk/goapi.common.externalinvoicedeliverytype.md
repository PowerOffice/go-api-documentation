
ExternalInvoiceDeliveryType
================

Enum ExternalInvoiceDeliveryType to specify how an external third party should deliver an invoice / credit note to a customer.

### Fields
Name |Value | Description
:----|:-----|:-----------
Unspecified|0|Not specified
Print|1|Invoice should be printed out and delivered physically
PdfByEmail|2|Invoice should be sent by email to the customer
Ehf|3|Invoice should be delivered by EHF
