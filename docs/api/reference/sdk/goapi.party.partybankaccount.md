
PartyBankAccount
================

PartyBankAccount representing a bank account on a party ( [Customer](GoApi.Party.Customer.md) , [Supplier](GoApi.Party.Supplier.md) or [Employee](GoApi.Party.Employee.md) ).


### Properties
Name | Description
:----|:------------
[Id](GoApi.Party.PartyBankAccount.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[BankCode](GoApi.Party.PartyBankAccount.BankCode.md)|Gets or sets the bank code used in countries that does not support BicSwift.
[BicSwift](GoApi.Party.PartyBankAccount.BicSwift.md)|Gets or sets the bic swift.
[Code](GoApi.Party.PartyBankAccount.Code.md)|Gets or sets the code. This is either a domestic bank account code or a IBAN number.
[CountryCode](GoApi.Party.PartyBankAccount.CountryCode.md)|Gets or sets the country code.
[IsActive](GoApi.Party.PartyBankAccount.IsActive.md)|Gets or sets a value indicating whether this bank account is active.
[LastChanged](GoApi.Party.PartyBankAccount.LastChanged.md)|Gets the last changed date.
[PartyId](GoApi.Party.PartyBankAccount.PartyId.md)|Gets the id of the party ( [Customer](GoApi.Party.Customer.md) , [Supplier](GoApi.Party.Supplier.md) or [Employee](GoApi.Party.Employee.md) ) this bank account is for.
