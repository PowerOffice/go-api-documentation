
VatPeriod
================

Enum defining the Value Added Tax (VAT) period on this client. The VAT period states how often VAT is reported to the government from this client.

### Fields
Name |Value | Description
:----|:-----|:-----------
None|0|No defined VAT period
Weekly|1|Every week
HalfMonthly|2|Half-Monthly
Monthly|3|Every month
BiMonthly|4|Every two months
Yearly|5|Once a year
HalfYearly|6|Twice a year
Quarterly|7|Four times a year
