
TimeTrackingEntry.IsTransferedToPayroll
================
**Namespace:** GoApi.TimeTracking

Gets a value indicating whether this instance is transferred to payroll. Time tracking entries that have been transferred to payroll can no longer be edited.

### Syntax
```csharp
	public Nullable<System.bool> IsTransferedToPayroll { get; internal set; }
```

### Type

System.Nullable&lt;System.bool&gt;
