
ProjectActivity
================

Project Activity representing an [Activity](GoApi.TimeTracking.Activity.md) on a Project.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Projects.ProjectActivity.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[ActivityCode](GoApi.Projects.ProjectActivity.ActivityCode.md)|Gets or sets the code of the [Activity](GoApi.TimeTracking.Activity.md) .
[HourlyRate](GoApi.Projects.ProjectActivity.HourlyRate.md)|Gets or sets the hourly rate of this project activity. If this value is *null* , the value is retrieved from the associated [Activity](GoApi.TimeTracking.Activity.md) when billing this project.
[IsBillable](GoApi.Projects.ProjectActivity.IsBillable.md)|Gets or sets whether this project activity represents billable time. If this value is *null* , the value is retrieved from the associated [Activity](GoApi.TimeTracking.Activity.md) when billing this project.
[Name](GoApi.Projects.ProjectActivity.Name.md)|Gets the name of the activity.
[ProjectCode](GoApi.Projects.ProjectActivity.ProjectCode.md)|Gets the code of the [Project](GoApi.Projects.Project.md) .
