
DeliveryTerm
================

DeliveryTerm representing a delivery term available for use on the client. A delivery terms is the terms of delivery that is stated on orders or invoices.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Invoices.DeliveryTerm.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[IsDefault](GoApi.Invoices.DeliveryTerm.IsDefault.md)|Gets or sets if this delivery term is default.
[Name](GoApi.Invoices.DeliveryTerm.Name.md)|Gets or sets the name of the delivery term.
