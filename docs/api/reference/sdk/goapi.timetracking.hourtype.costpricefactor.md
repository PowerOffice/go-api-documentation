
HourType.CostPriceFactor
================
**Namespace:** GoApi.TimeTracking

A multiplication factor used to determine how much the cost price should be altered. Defaults to 1. (100%)     Example: A person working 100% overtime, costs twice as much.

### Syntax
```csharp
	public Nullable<System.decimal> CostPriceFactor { get; set; }
```
