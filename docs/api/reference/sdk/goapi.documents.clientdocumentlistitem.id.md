
ClientDocumentListItem.Id
================
**Namespace:** GoApi.Documents

The Id of the document entity. Is not used when adding a new [ClientDocument](GoApi.Documents.ClientDocument.md) .         When adding a new version, the Id should be set to the current [ClientDocument](GoApi.Documents.ClientDocument.md) .
