
DebtCollectionInvoiceMatch.ExternalImportReference
================
**Namespace:** GoApi.DebtCollection

Gets the ExternalImportReference that was provided when creating the invoice. This value will only have a value if the voucher was created outside PowerOffice Go and imported with a reference.

### Syntax
```csharp
	public string ExternalImportReference { get; internal set; }
```

### Type

string
