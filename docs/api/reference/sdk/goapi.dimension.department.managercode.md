
Department.ManagerCode
================
**Namespace:** GoApi.Dimension

Gets or sets the [Employee](GoApi.Party.Employee.md) code of the manager on this department.     There must exist an [Employee](GoApi.Party.Employee.md) with the code provided to set it as manager code.

### Syntax
```csharp
	public Nullable<System.long> ManagerCode { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
