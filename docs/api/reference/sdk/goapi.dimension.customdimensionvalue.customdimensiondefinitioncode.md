
CustomDimensionValue.CustomDimensionDefinitionCode
================
**Namespace:** GoApi.Dimension

Gets or sets the custom dimension definition code.     When creating a new CustomDimensionValue either CustomDimensionDefinitionCode or CustomDimensionOrdinal must be provided and CustomDimensionDefinitionCode takes precedence when both are provided

### Syntax
```csharp
	public string CustomDimensionDefinitionCode { get; set; }
```

### Type

string
