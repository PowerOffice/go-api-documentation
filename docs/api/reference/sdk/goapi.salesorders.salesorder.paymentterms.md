
SalesOrder.PaymentTerms
================
**Namespace:** GoApi.SalesOrders

Gets or sets the payment terms. This is the number of days until the invoice is due after it's sent.         If set to *null* , default payment term on customer will be used.

### Syntax
```csharp
	public Nullable<System.int> PaymentTerms { get; set; }
```

### Type

System.Nullable&lt;System.int&gt;
