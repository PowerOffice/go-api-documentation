
BankJournalVoucherLine.InvoiceNo
================
**Namespace:** GoApi.Voucher

Gets or sets the invoice number that this payment is for. If provided, and the AccountCode is for a sub ledger account, the import will try to match the accounting entry with an invoice on the sub ledger account.

### Syntax
```csharp
	public string InvoiceNo { get; set; }
```

### Type

string
