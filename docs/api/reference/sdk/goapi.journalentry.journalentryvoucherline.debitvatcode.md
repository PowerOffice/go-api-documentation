
JournalEntryVoucherLine.DebitVatCode
================
**Namespace:** GoApi.JournalEntry

The code of the [VatCode](GoApi.Dimension.VatCode.md) of the debit entry.     If not provided, the default vat code of the account setting for the DebitAccountCode will be used. The settings can be queried using the GeneralLedgerAccount service.

	public string DebitVatCode { get; set; }
