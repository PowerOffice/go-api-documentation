
ExpenseVoucher.DueDate
================
**Namespace:** GoApi.Voucher

Gets or sets the due date. If not provided, the due date of the expense voucher will be set to VoucherDate.

### Syntax
```csharp
	public Nullable<System.DateTime> DueDate { get; set; }
```
