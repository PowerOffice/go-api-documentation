
ImportLine.SupplierCode
================
**Namespace:** GoApi.Import

Gets or sets code of the [Supplier](GoApi.Party.Supplier.md) to post on. GoApi.Import.ImportLine.AccountNumber will be ignored on entries posted on a sub ledger account.

### Syntax
```csharp
	public Nullable<System.long> SupplierCode { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
