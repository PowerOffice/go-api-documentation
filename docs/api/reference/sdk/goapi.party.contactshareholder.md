
ContactShareholder
================

ContactShareholder representing a shareholder for a [Customer](GoApi.Party.Customer.md) or [Supplier](GoApi.Party.Supplier.md) .


### Properties
Name | Description
:----|:------------
[Id](GoApi.Party.ContactShareholder.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[Address](GoApi.Party.ContactShareholder.Address.md)|Gets or sets the address of the shareholder.
[CountryOfResidence](GoApi.Party.ContactShareholder.CountryOfResidence.md)|Gets or sets the country code of the shareholders residence.
[FirstName](GoApi.Party.ContactShareholder.FirstName.md)|Gets or sets the first name.         Usage is recommended if the contact is a person.
[IdNumber](GoApi.Party.ContactShareholder.IdNumber.md)|Gets or sets identification number of the shareholder.         This is usually a organization number if the shareholder is an organization.
[IsPep](GoApi.Party.ContactShareholder.IsPep.md)|Gets or sets if the shareholder is a politically exposed (PEP).
[IsPerson](GoApi.Party.ContactShareholder.IsPerson.md)|Gets or sets if the contact is a person. Otherwise the contact is a company.
[IsRca](GoApi.Party.ContactShareholder.IsRca.md)|Gets or sets if the shareholder has relatives or close associates of PEP
[LastChanged](GoApi.Party.ContactShareholder.LastChanged.md)|Gets the last changed date.
[LastName](GoApi.Party.ContactShareholder.LastName.md)|Gets or sets the last name.         Usage is recommended if the contact is a person.
[Name](GoApi.Party.ContactShareholder.Name.md)|Gets or sets the name of the contact.
[PartyCustomerCode](GoApi.Party.ContactShareholder.PartyCustomerCode.md)|Gets the code of the [Customer](GoApi.Party.Customer.md) if the shareholder is connected to a customer
[PartyId](GoApi.Party.ContactShareholder.PartyId.md)|Gets the id of the [Customer](GoApi.Party.Customer.md) or [Supplier](GoApi.Party.Supplier.md) this shareholder is for.
[PartySupplierCode](GoApi.Party.ContactShareholder.PartySupplierCode.md)|Gets the code of the [Supplier](GoApi.Party.Supplier.md) if the shareholder is connected to a supplier
[Share](GoApi.Party.ContactShareholder.Share.md)|Gets or sets the share percentage. This value should be between 0 and 1 - i.e. 50% ownership = 0.50
