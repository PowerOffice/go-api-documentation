
GeneralLedgerAccount.Code
================
**Namespace:** GoApi.AccountingSettings

Gets or sets the code. This is a required property when creating new general ledger accounts and the value has to be in the range 1000-9999.

### Syntax
```csharp
	public Nullable<System.long> Code { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
