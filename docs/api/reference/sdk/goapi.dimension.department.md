
Department
================

Department representing a department on the client.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Dimension.Department.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[Code](GoApi.Dimension.Department.Code.md)|Gets or sets the code. This code must be unique for each department.
[CreatedFromImportJournalId](GoApi.Dimension.Department.CreatedFromImportJournalId.md)|Gets the created from import journal identifier. If the department was created from an import, this property will contain the ID of the [Import](GoApi.Import.Import.md) that created this account.
[IsActive](GoApi.Dimension.Department.IsActive.md)|Gets or sets a value indicating whether this instance is active.
[LastChanged](GoApi.Dimension.Department.LastChanged.md)|Gets the last changed date.
[ManagerCode](GoApi.Dimension.Department.ManagerCode.md)|Gets or sets the [Employee](GoApi.Party.Employee.md) code of the manager on this department.     There must exist an [Employee](GoApi.Party.Employee.md) with the code provided to set it as manager code.
[Name](GoApi.Dimension.Department.Name.md)|Gets or sets the name of the department.
