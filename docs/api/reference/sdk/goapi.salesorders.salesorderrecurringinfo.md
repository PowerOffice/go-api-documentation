
SalesOrderRecurringInfo
================

Class containing info about whether a [SalesOrder](GoApi.SalesOrders.SalesOrder.md) is recurring (repeating).


### Properties
Name | Description
:----|:------------
[Id](GoApi.SalesOrders.SalesOrderRecurringInfo.Id.md)|Gets or sets the identifier. This is assigned by PowerOffice Go when saving.
[NextRecurringInvoiceDate](GoApi.SalesOrders.SalesOrderRecurringInfo.NextRecurringInvoiceDate.md)|Gets or sets the next recurring invoice date.
[RecurringDaysInAdvance](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringDaysInAdvance.md)|Gets or sets a number of days in advance of the next recurring invoice date the invoice will be processed.
[RecurringInvoiceActive](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringInvoiceActive.md)|Gets or sets a value indicating whether [recurring invoice active]. Must be set to true to create the [SalesOrder](GoApi.SalesOrders.SalesOrder.md) as a recurring invoice.
[RecurringInvoiceEndDate](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringInvoiceEndDate.md)|Gets or sets the recurring invoice end date.
[RecurringInvoiceRepeatTimes](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringInvoiceRepeatTimes.md)|Gets or sets the recurring invoice repeat times.
[RecurringInvoiceSendFrequency](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringInvoiceSendFrequency.md)|Gets or sets the recurring invoice send frequency.
[RecurringSendFrequencyUnit](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringSendFrequencyUnit.md)|Gets or sets the recurring send frequency unit.
[RecurringSendMethod](GoApi.SalesOrders.SalesOrderRecurringInfo.RecurringSendMethod.md)|Gets or sets the recurring invoice send method.
