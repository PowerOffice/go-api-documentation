
ClientContact
================

Client contact is representing a contact of the client. Usually this is the board of directors and the general manager.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Client.ClientContact.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved.
[BornYear](GoApi.Client.ClientContact.BornYear.md)|Gets the contact person birth year. For contact persons where the year born is set, this property will contain the first date in the given year.
[Email](GoApi.Client.ClientContact.Email.md)|Gets the contact person email address.
[FirstName](GoApi.Client.ClientContact.FirstName.md)|Gets the first name of the contact person.
[LastName](GoApi.Client.ClientContact.LastName.md)|Gets the last name of the contact person.
[PhoneNumber](GoApi.Client.ClientContact.PhoneNumber.md)|Gets the contact person phone number.
[Role](GoApi.Client.ClientContact.Role.md)|Gets the contact person role for this client.
