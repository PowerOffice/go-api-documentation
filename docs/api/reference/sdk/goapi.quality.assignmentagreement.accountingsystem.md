
AssignmentAgreement.AccountingSystem
================
**Namespace:** GoApi.Quality

Gets or sets the accounting system used. If PowerOffice Go is used, the property AccountingSystemIsPowerOfficeGo must be set to true. Represents the Accounting system found under Data and System in the Assignment Assessment tab.

### Syntax
```csharp
	public string AccountingSystem { get; set; }
```

### Type

string
