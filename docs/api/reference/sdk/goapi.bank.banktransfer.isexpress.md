
BankTransfer.IsExpress
================
**Namespace:** GoApi.Bank

Gets or sets a value indicating whether this instance is express. This feature can be used on international payments to speed up payment processing, but banks may take extra charges.

### Syntax
```csharp
	public Nullable<System.bool> IsExpress { get; set; }
```

### Type

System.Nullable&lt;System.bool&gt;
