
OutgoingInvoiceLine.DiscountPercent
================
**Namespace:** GoApi.Invoices

Gets or sets the discount. The value must be between 0 and 1. I.e. 0.5 = 50% discount.         Can also be used to add a premium in percent of the sales price (usually markup) by having negative number. Negative numbers can be between -10 and 0.

### Syntax
```csharp
	public Nullable<System.decimal> DiscountPercent { get; set; }
```

### Type

System.Nullable&lt;System.decimal&gt;
