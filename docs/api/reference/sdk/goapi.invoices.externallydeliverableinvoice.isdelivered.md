
ExternallyDeliverableInvoice.IsDelivered
================
**Namespace:** GoApi.Invoices

Gets the flag indicating whether this invoice has already been delivered. The external third party can set this flag though the deliver method on the ExternalDeliverableInvoice service.

### Syntax
```csharp
	public bool IsDelivered { get; internal set; }
```

### Type

bool
