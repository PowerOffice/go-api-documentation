
BankTransfer.BalancingAccountNo
================
**Namespace:** GoApi.Bank

Gets or sets the balancing account no. This is the account that will be debited when the remittance is posted and is required when creating new bank tranfers.

### Syntax
```csharp
	public Nullable<System.long> BalancingAccountNo { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
