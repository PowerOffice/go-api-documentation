
Project.HourlyRateFactorWithMarkup
================
**Namespace:** GoApi.Projects

Gets or sets the overridden markup factor used when billing hours on this project. This is the factor including the amount, e.g. if it should be added a 50% increase to hourly rate by markup this value should be 1.5.

### Syntax
```csharp
	public Nullable<System.decimal> HourlyRateFactorWithMarkup { get; set; }
```

### Type

System.Nullable&lt;System.decimal&gt;
