
VoucherLineBase.ProjectCode
================
**Namespace:** GoApi.Voucher

Gets or sets the code of the [Project](GoApi.Projects.Project.md) .         If set to "-1", this line will not inherit the project set on the voucher level, and no project will be posted to Go for this line

### Syntax
```csharp
	public string ProjectCode { get; set; }
```

### Type

string
