
JournalEntryVoucherLine.Quantity
================
**Namespace:** GoApi.JournalEntry

Gets or sets the quantity of the related product, if product is set on the line. If this quantity is set and no product is set, this property will be ignored when posted.

### Syntax
```csharp
	public Nullable<System.decimal> Quantity { get; set; }
```

### Type

System.Nullable&lt;System.decimal&gt;
