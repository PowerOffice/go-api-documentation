
ProjectActivity.IsBillable
================
**Namespace:** GoApi.Projects

Gets or sets whether this project activity represents billable time. If this value is *null* , the value is retrieved from the associated [Activity](GoApi.TimeTracking.Activity.md) when billing this project.

### Syntax
```csharp
	public Nullable<System.bool> IsBillable { get; set; }
```

### Type

System.Nullable&lt;System.bool&gt;
