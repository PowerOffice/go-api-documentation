
RemittanceInfoRequest.ClientBankAccountCode
================
**Namespace:** GoApi.Voucher

The bank account code of the [Client](GoApi.Client.Client.md) that should be paid from. If not provided, the CurrentBankAccount set in ClientSettings will be used.         Bank account code is required if UseRemittance is true.

### Syntax
```csharp
	public string ClientBankAccountCode { get; set; }
```

### Type

string
