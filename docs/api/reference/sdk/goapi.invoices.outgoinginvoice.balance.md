
OutgoingInvoice.Balance
================
**Namespace:** GoApi.Invoices

Gets the remaining amount to be paid on this invoice. This field will only have a value on sent or paid invoices and is shown in the client's default currency code.

### Syntax
```csharp
	public Nullable<System.decimal> Balance { get; internal set; }
```

### Type

System.Nullable&lt;System.decimal&gt;
