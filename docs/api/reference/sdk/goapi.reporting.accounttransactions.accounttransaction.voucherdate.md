
AccountTransaction.VoucherDate
================
**Namespace:** GoApi.Reporting.AccountTransactions

Gets the date of the voucher. This represents the date of the voucher, the document date of an invoice for instance,     and may differ from the transaction dates for the voucher.     Always present on transactions.

### Syntax
```csharp
	public Nullable<System.DateTime> VoucherDate { get; set; }
```

### Type

System.Nullable&lt;System.DateTime&gt;
