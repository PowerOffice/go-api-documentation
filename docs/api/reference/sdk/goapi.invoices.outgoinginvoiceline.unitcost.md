
OutgoingInvoiceLine.UnitCost
================
**Namespace:** GoApi.Invoices

Gets or sets the overridden unit cost price for this [Product](GoApi.Products.Product.md) . If this is not provided, the unit cost price on the product will be set.

### Syntax
```csharp
	public Nullable<System.decimal> UnitCost { get; set; }
```

### Type

System.Nullable&lt;System.decimal&gt;
