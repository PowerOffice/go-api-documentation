
OutgoingInvoice.CustomerReferenceContactPersonId
================
**Namespace:** GoApi.Invoices

Gets or sets the customer reference contact person id. This property will be used instead of CustomerReference if provided. The customer must have a contact person with this ID created to use this property.

### Syntax
```csharp
	public Nullable<System.long> CustomerReferenceContactPersonId { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
