
InvoiceJournalLine.ExpectedDueDate
================
**Namespace:** GoApi.Reporting.InvoiceJournal

Gets the expected due date. This is a manually overrideable date that can be set on invoices where a user has given an extended amount of credit days before the invoice is due, after the invoice has been sent.

### Syntax
```csharp
	public Nullable<System.DateTime> ExpectedDueDate { get; internal set; }
```

### Type

System.Nullable&lt;System.DateTime&gt;
