
FinancingService
================

Service that provides methods for financial agencies to query and updating [FinancialStatus](GoApi.Financing.FinancialStatus.md) on the client.



### Constructors
Name | Description
:----|:------------
[FinancingService(IAuthorization authorization, Host host)](GoApi.Financing.FinancingService.FinancingService_IAuthorization_authorization__Host_host_.md)|Initializes a new instance of the [FinancingService](GoApi.Financing.FinancingService.md) class.

### Methods
Name | Description
:----|:------------
[Get()](GoApi.Financing.FinancingService.Get__.md)|Gets the [FinancialStatus](GoApi.Financing.FinancialStatus.md) for given client.
[UpdateFinancialStatus(FinancialStatus request)](GoApi.Financing.FinancingService.UpdateFinancialStatus_FinancialStatus_request_.md)|Updates the [FinancialStatus](GoApi.Financing.FinancialStatus.md) of the client with the credit limit and the amount of the credit that has been used by the client.
