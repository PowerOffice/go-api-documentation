ClientIntegrationInformation.ActiveClientSubscriptions
================
**Namespace:** GoApi

All active Go-subscriptions for the client.
Available subscriptions:
- Accounting (Regnskap og faktura)
- TimeTracking (Timeregistrering)
- Payroll (Lønn)
- TravelExpense (Reiseregning)
- AccountingMicro (Regnskap Mikro)
- Quality
- HolidayAndLeave (Ferie og fravær)
- CustomerCheck (kundesjekk.no)
- AccountingNano (Regnskap og faktura)
- YearEndSoleProprietorship (Skattemelding ENK)

### Syntax
```csharp
	public IEnumerable<string> ActiveClientSubscriptions { get; set; }
```

### Type

System.Collections.Generic.IEnumerable&lt;string&gt;
