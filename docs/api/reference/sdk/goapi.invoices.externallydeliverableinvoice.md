
ExternallyDeliverableInvoice
================

ExternallyDeliverableInvoice representing an outgoing invoice or credit note that is to be delivered by an external third party to a customer.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Invoices.ExternallyDeliverableInvoice.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved
[CreatedDate](GoApi.Invoices.ExternallyDeliverableInvoice.CreatedDate.md)|Gets the date this entity was created.
[CustomerCode](GoApi.Invoices.ExternallyDeliverableInvoice.CustomerCode.md)|Gets the code of the [Customer](GoApi.Party.Customer.md) that this invoice is to be delivered to.
[CustomerEmail](GoApi.Invoices.ExternallyDeliverableInvoice.CustomerEmail.md)|Gets the customer email specified on this invoice.
[DueDate](GoApi.Invoices.ExternallyDeliverableInvoice.DueDate.md)|Gets the due date of the invoice.
[ExternalInvoiceDeliveryType](GoApi.Invoices.ExternallyDeliverableInvoice.ExternalInvoiceDeliveryType.md)|Gets the type of delivery that is supposed to be used by the external third party.
[InvoiceDate](GoApi.Invoices.ExternallyDeliverableInvoice.InvoiceDate.md)|Gets the invoice date.
[InvoiceDeliveryDate](GoApi.Invoices.ExternallyDeliverableInvoice.InvoiceDeliveryDate.md)|Gets the invoice delivery date.
[InvoiceNo](GoApi.Invoices.ExternallyDeliverableInvoice.InvoiceNo.md)|Gets the invoice number.
[IsDelivered](GoApi.Invoices.ExternallyDeliverableInvoice.IsDelivered.md)|Gets the flag indicating whether this invoice has already been delivered. The external third party can set this flag though the deliver method on the ExternalDeliverableInvoice service.
[TotalAmount](GoApi.Invoices.ExternallyDeliverableInvoice.TotalAmount.md)|Gets the total amount of the invoice.
