
OutgoingInvoiceLine.DepartmentCode
================
**Namespace:** GoApi.Invoices

Gets or sets code of the [Department](GoApi.Dimension.Department.md) this line is for.         By default the DepartmentCode in the head (OutgoingInvoice) will be inherited and used when this is null.         Use "-1" to set "No department".

### Syntax
```csharp
	public string DepartmentCode { get; set; }
```

### Type

string
