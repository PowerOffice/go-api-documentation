
Import.File
================
**Namespace:** GoApi.Import

Gets or sets the [ImportFile](GoApi.Import.ImportFile.md) . If provided, this import will import the file and ignore GoApi.Import.Import.ImportLines and GoApi.Import.Import.SalesOrders objects.

### Syntax
```csharp
	public ImportFile File { get; set; }
```
