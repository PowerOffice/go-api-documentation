
AccountTransaction.ImportedVoucherNo
================
**Namespace:** GoApi.Reporting.AccountTransactions

Gets the number that the voucher that generated this accounting entry has in an external system. This property will only contain a value on imported vouchers.

### Syntax
```csharp
	public Nullable<System.long> ImportedVoucherNo { get; set; }
```

### Type

System.Nullable&lt;System.long&gt;
