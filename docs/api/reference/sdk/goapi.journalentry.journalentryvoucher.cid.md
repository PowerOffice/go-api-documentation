
JournalEntryVoucher.CID
================
**Namespace:** GoApi.JournalEntry

Field representing the customer identification code (Norwegian: KID-nummer) on the voucher. Can be used on vouchers of type GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice and GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote .

### Syntax
```csharp
	public string CID { get; set; }
```

### Type

string
