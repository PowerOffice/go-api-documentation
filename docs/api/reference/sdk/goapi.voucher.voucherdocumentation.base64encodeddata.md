
VoucherDocumentation.Base64EncodedData
================
**Namespace:** GoApi.Voucher

Gets or sets the file as Base64 encoded data. Required when adding VoucherDocumentation. Importing a new file requires the file type to be pdf. The file size must be less than 50Mb.

### Syntax
```csharp
	public string Base64EncodedData { get; set; }
```

### Type

string
