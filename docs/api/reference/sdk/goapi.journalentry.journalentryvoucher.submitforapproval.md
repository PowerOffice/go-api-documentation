
JournalEntryVoucher.SubmitForApproval
================
**Namespace:** GoApi.JournalEntry

Gets or sets whether Go should try to auto-submit the voucher to approval instead of uploading it to journal entry. This feature will only work on suppliers that have been configured for auto approval in PowerOffice.

### Syntax
```csharp
	public Nullable<System.bool> SubmitForApproval { get; set; }
```

### Type

System.Nullable&lt;System.bool&gt;
