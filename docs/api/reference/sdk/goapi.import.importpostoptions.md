
ImportPostOptions
================

ImportPostOptions that can be used to specify additional settings when importing.


### Properties
Name | Description
:----|:------------
[WaitTimeout](GoApi.Import.ImportPostOptions.WaitTimeout.md)|Gets or sets the wait timeout.
[WaitUntilCompletion](GoApi.Import.ImportPostOptions.WaitUntilCompletion.md)|Gets or sets a value indicating whether to wait until post has been completed, or return immediately.     If WaitTimeout has been set the wait will throw an exception when the [WaitTimeout] amount of time has passed.
