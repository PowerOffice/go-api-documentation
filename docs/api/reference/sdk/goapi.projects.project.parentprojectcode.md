
Project.ParentProjectCode
================
**Namespace:** GoApi.Projects

Gets or sets the code of the parent project. Mandatory for sub projects.         If the new project is a sub project, the ParentProjectCode must be set to the Code of the parent project. Otherwise it will be treated as a new main project.

### Syntax
```csharp
	public string ParentProjectCode { get; set; }
```

### Type

string
