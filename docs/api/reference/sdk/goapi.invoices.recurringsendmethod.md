
RecurringSendMethod
================

Describes what happens to a recurring invoice when the invoice date is reached.

### Fields
Name |Value | Description
:----|:-----|:-----------
Confirm|0|The invoice will be saved as a confirmed invoice when the invoice date is reached.
Send|1|Invoice will be sent to the customer when the invoice date is reached.
Draft|2|Invoice will be saved as an invoice draft only
