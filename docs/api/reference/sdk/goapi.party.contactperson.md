
ContactPerson
================

ContactPerson representing a contact person for a party ( [Customer](GoApi.Party.Customer.md) or [Supplier](GoApi.Party.Supplier.md) ).


### Properties
Name | Description
:----|:------------
[Id](GoApi.Party.ContactPerson.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[Address1](GoApi.Party.ContactPerson.Address1.md)|Gets or sets the first address line.
[Address2](GoApi.Party.ContactPerson.Address2.md)|Gets or sets the second address line.
[Citizenship](GoApi.Party.ContactPerson.Citizenship.md)|Gets or sets the citizenship ISO 3166-1 alfa-2 country codes (Two characters) of this contact person.
[City](GoApi.Party.ContactPerson.City.md)|Gets or sets the address city.
[DateOfBirth](GoApi.Party.ContactPerson.DateOfBirth.md)|Gets or sets the date of birth of this contact person.
[EmailAddress](GoApi.Party.ContactPerson.EmailAddress.md)|Gets or sets the email address.
[ExternalCode](GoApi.Party.ContactPerson.ExternalCode.md)|Gets or sets the external code - can be used to reference the contact person in the external system.
[FirstName](GoApi.Party.ContactPerson.FirstName.md)|Gets or sets the first name.
[Gender](GoApi.Party.ContactPerson.Gender.md)|Gets or sets the [Gender](GoApi.Common.Gender.md) of this contact person.
[HasNorwegianSSN](GoApi.Party.ContactPerson.HasNorwegianSSN.md)|Gets or sets a value indicative of whether this contact person has a norwegian social security number or not
[IsActive](GoApi.Party.ContactPerson.IsActive.md)|Gets or sets a value indicating whether this contact person is active.
[IsPep](GoApi.Party.ContactPerson.IsPep.md)|Gets or sets if the contact person is a politically exposed person (PEP).
[IsRca](GoApi.Party.ContactPerson.IsRca.md)|Gets or sets if the contact person has relatives or close associates of PEP (RCA)
[LastChanged](GoApi.Party.ContactPerson.LastChanged.md)|Gets the last changed date.
[LastName](GoApi.Party.ContactPerson.LastName.md)|Gets or sets the last name.
[PartyCustomerCode](GoApi.Party.ContactPerson.PartyCustomerCode.md)|Gets the code of the [Customer](GoApi.Party.Customer.md) that this contact person is associated with
[PartyId](GoApi.Party.ContactPerson.PartyId.md)|Gets the id of the [Customer](GoApi.Party.Customer.md) and/or [Supplier](GoApi.Party.Supplier.md) this contact person is for.
[PartySupplierCode](GoApi.Party.ContactPerson.PartySupplierCode.md)|Gets the code of the [Supplier](GoApi.Party.Supplier.md) that this contact person is associated with
[PhoneNumber](GoApi.Party.ContactPerson.PhoneNumber.md)|Gets or sets the phone number.
[PlaceOfBirth](GoApi.Party.ContactPerson.PlaceOfBirth.md)|Gets or sets the place of birth of this contact person.
[ResidenceCountryCode](GoApi.Party.ContactPerson.ResidenceCountryCode.md)|Gets or sets the ISO 3166-1 alfa-2 country code (Two characters) of this contact persons country of residence.
[SocialSecurityNumber](GoApi.Party.ContactPerson.SocialSecurityNumber.md)|Sets the social security number for this contact person
[ZipCode](GoApi.Party.ContactPerson.ZipCode.md)|Gets or sets the address zip code.
