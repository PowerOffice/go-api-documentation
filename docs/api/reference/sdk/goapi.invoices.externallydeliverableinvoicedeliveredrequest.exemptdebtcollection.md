
ExternallyDeliverableInvoiceDeliveredRequest.ExemptDebtCollection
================
**Namespace:** GoApi.Invoices

Flag indicating that the invoice should not go to debt collection. When this is set to true, the invoice is set "on hold" in Go.

### Syntax
```csharp
	public bool ExemptDebtCollection { get; set; }
```

### Type
