
PaymentTerm
================

Class representing Payment Terms. A payment term is the number of days from a [OutgoingInvoice](GoApi.Invoices.OutgoingInvoice.md) is sent until it's due.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Invoices.PaymentTerm.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[CreditDays](GoApi.Invoices.PaymentTerm.CreditDays.md)|Gets or sets the number of credit days.
[IsDefault](GoApi.Invoices.PaymentTerm.IsDefault.md)|Gets or sets if this payment term is default.
[Name](GoApi.Invoices.PaymentTerm.Name.md)|Gets or sets the name of the payment term.
