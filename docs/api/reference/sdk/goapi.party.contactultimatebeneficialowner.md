
ContactUltimateBeneficialOwner
================

ContactUltimateBeneficialOwner representing a ultimate beneficial owner (UBO) for a [Customer](GoApi.Party.Customer.md) or [Supplier](GoApi.Party.Supplier.md) .     An UBO is a party that is an indirect shareholder of the contact.


### Properties
Name | Description
:----|:------------
[Id](GoApi.Party.ContactUltimateBeneficialOwner.Id.md)|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
[Address](GoApi.Party.ContactUltimateBeneficialOwner.Address.md)|Gets or sets the address of the ultimate beneficial owner.
[CountryOfResidence](GoApi.Party.ContactUltimateBeneficialOwner.CountryOfResidence.md)|Gets or sets the country code of the ultimate beneficial owner residence.
[FirstName](GoApi.Party.ContactUltimateBeneficialOwner.FirstName.md)|Gets or sets the first name.         Usage is recommended if the contact is a person.
[GroundsForUBOStatus](GoApi.Party.ContactUltimateBeneficialOwner.GroundsForUBOStatus.md)|Gets or sets grounds for UBO status.
[HasVotingRights](GoApi.Party.ContactUltimateBeneficialOwner.HasVotingRights.md)|Gets or sets if the ultimate beneficial owner has voting rights.
[IdNumber](GoApi.Party.ContactUltimateBeneficialOwner.IdNumber.md)|Gets or sets identification number of the ultimate beneficial owner.         This is usually a organization number if the ultimate beneficial owner is an organization.
[IsPep](GoApi.Party.ContactUltimateBeneficialOwner.IsPep.md)|Gets or sets if the ultimate beneficial owner is politically exposed (PEP).
[IsRca](GoApi.Party.ContactUltimateBeneficialOwner.IsRca.md)|Gets or sets if the ultimate beneficial owner has relatives or close associates of PEP
[LastChanged](GoApi.Party.ContactUltimateBeneficialOwner.LastChanged.md)|Gets the last changed date.
[LastName](GoApi.Party.ContactUltimateBeneficialOwner.LastName.md)|Gets or sets the last name.         Usage is recommended if the contact is a person.
[Name](GoApi.Party.ContactUltimateBeneficialOwner.Name.md)|OBSOLETE - Gets or sets the name. Replaced by FirstName and LastName.
[PartyCustomerCode](GoApi.Party.ContactUltimateBeneficialOwner.PartyCustomerCode.md)|Gets the code of the [Customer](GoApi.Party.Customer.md) if the ultimate beneficial owner is connected to a customer
[PartyId](GoApi.Party.ContactUltimateBeneficialOwner.PartyId.md)|Gets the id of the [Customer](GoApi.Party.Customer.md) or [Supplier](GoApi.Party.Supplier.md) this ultimate beneficial owner is for.
[PartySupplierCode](GoApi.Party.ContactUltimateBeneficialOwner.PartySupplierCode.md)|Gets the code of the [Supplier](GoApi.Party.Supplier.md) if the ultimate beneficial owner is connected to a customer
[Share](GoApi.Party.ContactUltimateBeneficialOwner.Share.md)|Gets or sets the indirectly or directly owned percentage. This value should be between 0 and 1 - i.e. 50% ownership = 0.50
