
JournalEntryVoucher.SupplierCode
================
**Namespace:** GoApi.JournalEntry

The code of the [Supplier](GoApi.Party.Supplier.md) the invoice or credit note is from.      Can be used on vouchers with VoucherType GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice or GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote .

### Syntax
```csharp
	public Nullable<System.long> SupplierCode { get; set; }
```
