
ClientOnboardingRequestDto
================

Dto used by [ClientAuthService](GoApi.Client.ClientAuthService.md) when retrieving integration information through the RetrieveClientDataFromSessionId method.


### Properties
Name | Description
:----|:------------
[ApplicationKey](GoApi.Client.Dtos.ClientOnboardingRequestDto.ApplicationKey.md)|The secret application key of the integration that have previously been provided by PowerOffice AS.
[SessionId](GoApi.Client.Dtos.ClientOnboardingRequestDto.SessionId.md)|The session id that have been sent to the external integration when on-boarding from PowerOffice Go
