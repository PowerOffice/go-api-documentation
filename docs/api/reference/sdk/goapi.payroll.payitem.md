
PayItem
================

PayItem representing a pay item used on [SalaryLine](GoApi.Payroll.SalaryLine.md) on a Payroll. (Norwegian: Lønnsart).     It tells the payroll system how the individual salary line should be treated, so that it can be reported and posted in the correct manner on the payroll.


### Properties
Name | Description
:----|:------------
[Benefit](GoApi.Payroll.PayItem.Benefit.md)|Gets the benefit type. This is the benefit type reported on A02 when sending A-Melding to Altinn.
[Code](GoApi.Payroll.PayItem.Code.md)|Gets the code. This is an unique identification of the pay item.
[Description](GoApi.Payroll.PayItem.Description.md)|Gets the description. This is the benefit description reported on A02 when sending A-Melding to Altinn.
[Id](GoApi.Payroll.PayItem.Id.md)|Gets the ID of the pay item.
[IsActive](GoApi.Payroll.PayItem.IsActive.md)|Gets a value indicating whether this pay item is active.
[Name](GoApi.Payroll.PayItem.Name.md)|Gets the name of the pay item.
[ProcessingType](GoApi.Payroll.PayItem.ProcessingType.md)|Gets the processing type of the pay item.     They contain rules about how properties on the [SalaryLine](GoApi.Payroll.SalaryLine.md) should be calculated among other things.
