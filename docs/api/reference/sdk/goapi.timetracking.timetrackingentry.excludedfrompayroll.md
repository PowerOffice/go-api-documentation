
TimeTrackingEntry.ExcludedFromPayroll
================
**Namespace:** GoApi.TimeTracking

Gets or sets a value indicating whether this time tracking entry is should not be picked up by a payroll.      Setting this value to *true* makes Go Payroll ignore this time tracking entry when adding time transactions to the payroll.

### Syntax
```csharp
	public Nullable<System.bool> ExcludedFromPayroll { get; set; }
```

### Type

System.Nullable&lt;System.bool&gt;
