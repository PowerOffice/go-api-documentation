
ImportLine.CustomMatchingReference
================
**Namespace:** GoApi.Import

Gets or sets the custom matching reference. This value can be put on sub ledger entries (lines with CustomerNo, SupplierNo and EmployeeNo).     Lines with this value set will be matched with other entries with same CustomMatchingReference after the import is complete.

### Syntax
```csharp
	public string CustomMatchingReference { get; set; }
```

### Type

string
