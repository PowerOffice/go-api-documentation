
Employee.PayrollBankAccountCode
================
**Namespace:** GoApi.Party

Gets or sets the payroll bank account code.     Saving the employee entity will fail if the [PartyBankAccount](GoApi.Party.PartyBankAccount.md) with given code does not exist on the employee.

### Syntax
```csharp
	public string PayrollBankAccountCode { get; set; }
```

### Type

string
