
ProjectActivity.HourlyRate
================
**Namespace:** GoApi.Projects

Gets or sets the hourly rate of this project activity. If this value is *null* , the value is retrieved from the associated [Activity](GoApi.TimeTracking.Activity.md) when billing this project.

### Syntax
```csharp
	public Nullable<System.decimal> HourlyRate { get; set; }
```

### Type

System.Nullable&lt;System.decimal&gt;
