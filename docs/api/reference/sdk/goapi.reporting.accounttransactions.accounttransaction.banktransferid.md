
AccountTransaction.BankTransferId
================
**Namespace:** GoApi.Reporting.AccountTransactions

Gets the identifier of the [BankTransfer](GoApi.Bank.BankTransfer.md) . If provided on an accounting entry, this accounting entry is created from a remittance of a bank transfer with a given id.

### Syntax
```csharp
	public Nullable<System.Guid> BankTransferId { get; internal set; }
```

### Type

System.Nullable&lt;System.Guid&gt;
