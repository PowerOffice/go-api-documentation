
OutgoingInvoice.DueDate
================
**Namespace:** GoApi.Invoices

Gets the due date. This is the due date on the invoice that was sent from PowerOffice Go and will only have a value on sent invoices.

### Syntax
```csharp
	public Nullable<System.DateTime> DueDate { get; internal set; }
```

### Type

System.Nullable&lt;System.DateTime&gt;
