
FactoringInvoiceDetails.OriginalInvoiceNo
================
**Namespace:** GoApi.Factoring

Gets the invoice number of the invoice that this credit note is created from. This value can only be set on vouchers that are credit notes.

### Syntax
```csharp
	public Nullable<System.long> OriginalInvoiceNo { get; internal set; }
```

### Type
