
PayItemService
================

Service used to query [PayItem](GoApi.Payroll.PayItem.md) . (Norwegian: Lønnsarter)     Each pay item tells the payroll system how the individual salary line should be treated, so that it can be reported and posted in the correct manner on the payroll.
