
Client.IsVatRegistered
================
**Namespace:** GoApi.Client

Gets information whether this client is registered for Value Added Tax (VAT). (norwegian: mva-registrert)         If IsVatRegistered is false, vat is not be applied to outgoing invoices.

### Syntax
```csharp
	public bool IsVatRegistered { get; internal set; }
```

### Type

bool
