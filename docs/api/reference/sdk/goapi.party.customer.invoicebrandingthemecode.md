
Customer.InvoiceBrandingThemeCode
================
**Namespace:** GoApi.Party

Gets or sets the code of the [BrandingTheme](GoApi.Invoices.BrandingTheme.md) used when sending invoices to this customer. If NULL, the clients default branding theme will be used.

### Syntax
```csharp
	public string InvoiceBrandingThemeCode { get; set; }
```

### Type

string
