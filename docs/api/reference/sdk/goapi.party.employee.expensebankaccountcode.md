
Employee.ExpenseBankAccountCode
================
**Namespace:** GoApi.Party

Gets or sets the expense bank account code     Saving the employee entity will fail if the [PartyBankAccount](GoApi.Party.PartyBankAccount.md) with given code does not exist on the employee.
