
JournalEntryVoucher.PurchaseOrderNo
================
**Namespace:** GoApi.JournalEntry

Field representing the purchase order number on the voucher. Can be used on vouchers of type GoApi.JournalEntry.JournalEntryVoucherType.SupplierInvoice and GoApi.JournalEntry.JournalEntryVoucherType.SupplierCreditNote .

### Syntax
```csharp
	public string PurchaseOrderNo { get; set; }
```
