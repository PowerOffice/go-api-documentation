
JournalEntryVoucher.File
================
**Namespace:** GoApi.JournalEntry

The file containing the documentation of the voucher. This is displayed to the user assigned to post / approve this Voucher. Required for all voucher types.      File is always NULL in GET results from PowerOffice Go.
