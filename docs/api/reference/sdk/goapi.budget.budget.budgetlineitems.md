
Budget.BudgetLineItems
================
**Namespace:** GoApi.Budget

Gets or sets the budget line items. The line items is of type [BudgetLineItem](GoApi.Budget.BudgetLineItem.md) .         Each line is representing the budgeted amount of a single account on a specific budget period (Month).

### Syntax
```csharp
	public IEnumerable<GoApi.Budget.BudgetLineItem> BudgetLineItems { get; set; }
```
