
FactoringInvoiceStatus
================

Current status of the factoring invoice.

### Fields
Name |Value | Description
:----|:-----|:-----------
Unspecified|0|No status. Factoring not active. Error value only.
Active|1|Invoice is ready for factoring, but not yet delivered.
Forfeit|2|Factoring has stopped stopped.
Complained|3|Customer has complained to the factoring agency about an invoice.
Completed|4|Factoring on the invoice is completed.
Delivered|5|Invoice has been delivered to customer, still active
