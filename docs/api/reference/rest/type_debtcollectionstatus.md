
DebtCollectionStatus (number (Enum))
================


### Fields
Name |Value | Description
:----|:-----|:-----------
None|0|Not sent to debt collection
Draft|1|Sent to debt collection, but needs to be approved by a user before its transferred to the debt collection agency
OnHold|2|Sent to debt collection, but is set on hold
Approved|3|Sent to debt collection and approved for debt collection by user, but not yet retrieved by debt collection agency
Exported|4|Sent to debt collection and retrieved by debt collection agency
Rejected|10|Debt collection case was rejected by debt collection agency
