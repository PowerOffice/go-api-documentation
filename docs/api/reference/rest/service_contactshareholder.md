
ContactShareholder
================

Service providing methods for querying, creating and modifying [ContactShareholder](Type_ContactShareholder.md) .

**Base Url**: `https://api.poweroffice.net/ContactShareholder/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[ContactShareholder/](Route_GET_ContactShareholder__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [ContactShareholder](Type_ContactShareholder.md) filtered by odata query.
[ContactShareholder/](Route_POST_ContactShareholder_.md)|POST|Saves the specified [ContactShareholder](Type_ContactShareholder.md) .
[ContactShareholder/{id}](Route_DELETE_ContactShareholder__id__.md)|DELETE|Deletes the specified [ContactShareholder](Type_ContactShareholder.md) by its id.
