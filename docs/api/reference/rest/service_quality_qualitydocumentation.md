
QualityDocumentation
================

Service to upload and delete Quality Assignment agreement documentation.     Used to get Quality Assignment document list.     NB: Currently only for internal use.

**Base Url**: `https://api.poweroffice.net/Quality/QualityDocumentation/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Quality/QualityDocumentation/DeleteDocument/{id}](Route_DELETE_Quality_QualityDocumentation_DeleteDocument__id__.md)|DELETE|Delete a specific document.
[Quality/QualityDocumentation/GetDocumentList/{entityId}](Route_GET_Quality_QualityDocumentation_GetDocumentList__entityId__options__options_.md)?options=&lt;options&gt;|GET|Gets documents connected to an assignment agreement.
[Quality/QualityDocumentation/UploadDocument](Route_POST_Quality_QualityDocumentation_UploadDocument_.md)|POST|Uploads and connects a document to an assignment agreement.
