
ImportStatus (ImportStatus)
================



### Properties
Name | Type | Description
:----|:-----|:-----------
CanBePosted|boolean|Gets or sets a value indicating whether this instance is ready to be posted.
ErrorDescription|string|Gets the error description.
HasError|boolean|Gets a value indicating whether this instance has failed.
Id|string (Guid)|Gets or sets the identifier.
IsPosted|boolean|Gets or sets a value indicating whether this journal has been posted.
IsPosting|boolean|Gets a value indicating whether this instance is beeing posted, but has yet to be completed.
