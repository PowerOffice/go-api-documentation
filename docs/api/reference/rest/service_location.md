
Location
================

Service to query, create and update [Location](Type_Location.md)

**Base Url**: `https://api.poweroffice.net/Location/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Location/](Route_GET_Location__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of locations filtered by odata query.
[Location/](Route_POST_Location_.md)|POST|Creates or updates the specified location.
[Location/{id}](Route_GET_Location__id__.md)|GET|Gets the specified location by it's id.
[Location/{id}](Route_DELETE_Location__id__.md)|DELETE|Deletes the specified location by it's id.
