
SubledgerNumberSeries
================

Service that provides methods for querying [SubledgerNumberSeries](Type_SubledgerNumberSeries.md) on the client. (Norwegian: Reskontronummerserier)

**Base Url**: `https://api.poweroffice.net/SubledgerNumberSeries/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[SubledgerNumberSeries/](Route_GET_SubledgerNumberSeries__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of sub ledger number series filtered by odata query.
[SubledgerNumberSeries/{id}](Route_GET_SubledgerNumberSeries__id__.md)|GET|Gets the specified sub ledger number series by its identifier.
