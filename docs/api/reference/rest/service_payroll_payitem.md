
PayItem
================

Service used to query [PayItem](Type_PayItem.md) . (Norwegian: Lønnsarter)     Each pay item tells the payroll system how the individual salary line should be treated, so that it can be reported and posted in the correct manner on the payroll.

**Base Url**: `https://api.poweroffice.net/Payroll/PayItem/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Payroll/PayItem/](Route_GET_Payroll_PayItem__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [PayItem](Type_PayItem.md) filtered by odata query.
