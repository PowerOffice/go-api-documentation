
QualityAssignment
================

Service to create, update and delete [AssignmentAgreement](Type_AssignmentAgreement.md) . Only assignment agreements in status Draft can be edited.     NB: Currently only for internal use.

**Base Url**: `https://api.poweroffice.net/Quality/QualityAssignment/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Quality/QualityAssignment/](Route_GET_Quality_QualityAssignment__options__options_.md)?options=&lt;options&gt;|GET|Get a list of [AssignmentAgreement](Type_AssignmentAgreement.md) by an OData query.
[Quality/QualityAssignment/](Route_POST_Quality_QualityAssignment_.md)|POST|Saves the specified [AssignmentAgreement](Type_AssignmentAgreement.md) .
[Quality/QualityAssignment/{id}](Route_GET_Quality_QualityAssignment__id__.md)|GET|Get an [AssignmentAgreement](Type_AssignmentAgreement.md) by its Id.
[Quality/QualityAssignment/Delete/{id}](Route_DELETE_Quality_QualityAssignment_Delete__id__.md)|DELETE|Delete an [AssignmentAgreement](Type_AssignmentAgreement.md) .
