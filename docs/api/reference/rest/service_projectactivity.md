
ProjectActivity
================

Service to query [ProjectActivity](Type_ProjectActivity.md)

**Base Url**: `https://api.poweroffice.net/ProjectActivity/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[ProjectActivity/](Route_GET_ProjectActivity__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [ProjectActivity](Type_ProjectActivity.md) filtered by odata query.
[ProjectActivity/{id}](Route_GET_ProjectActivity__id__.md)|GET|Gets the specified [ProjectActivity](Type_ProjectActivity.md) by its id.
