
InvoiceStatus (number (Enum))
================


### Fields
Name |Value | Description
:----|:-----|:-----------
Unpaid|0|Invoice is unpaid.
Paid|1|The invoice has been paid.
PaymentNotificationSent|10|Invoice is unpaid and payment notification has been sent. This is not part of reminders, but a friendly reminder.
PaymentReminderSent|20|Invoice is unpaid and payment reminder has been sent.
NoticeOfDebtCollectionSent|30|Invoice is unpaid and notice of debt collection has been sent.
PaymentDemandSent|40|Invoice is unpaid and payment demand has been sent.
WarrantOfExecutionSent|50|Invoice is unpaid and warrant of execution has been sent.
