
Location (Location)
================



### Properties
Name | Type | Description
:----|:-----|:-----------
Code|string|Gets or sets the code of the location. This is an unique identificator.
Id|number|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
IsActive|boolean|Gets or sets a value indicating whether this location is active. Defaults to true.
Name|string|Gets or sets the name of the location.
