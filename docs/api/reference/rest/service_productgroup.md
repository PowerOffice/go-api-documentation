
ProductGroup
================

Service to query, create and update [ProductGroup](Type_ProductGroup.md)

**Base Url**: `https://api.poweroffice.net/ProductGroup/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[ProductGroup/](Route_GET_ProductGroup__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [ProductGroup](Type_ProductGroup.md) filtered by odata query.
[ProductGroup/](Route_POST_ProductGroup_.md)|POST|Creates or updates the specified [ProductGroup](Type_ProductGroup.md) .
[ProductGroup/{id}](Route_GET_ProductGroup__id__.md)|GET|Gets the specified [ProductGroup](Type_ProductGroup.md) by its identifier.
[ProductGroup/{id}](Route_DELETE_ProductGroup__id__.md)|DELETE|Deletes the specified [ProductGroup](Type_ProductGroup.md) by its identifier.
