
SalaryLine
================

Service that provides methods for querying and manipulating [SalaryLine](Type_SalaryLine.md) . These salary lines will appear on the next payroll generated in PowerOffice Go.

**Base Url**: `https://api.poweroffice.net/Payroll/SalaryLine/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Payroll/SalaryLine/](Route_GET_Payroll_SalaryLine__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [SalaryLine](Type_SalaryLine.md) filtered by odata query.
[Payroll/SalaryLine/](Route_POST_Payroll_SalaryLine_.md)|POST|Creates or updates the specified [SalaryLine](Type_SalaryLine.md) .
[Payroll/SalaryLine/{id}](Route_GET_Payroll_SalaryLine__id__.md)|GET|Gets the specified [SalaryLine](Type_SalaryLine.md) by its identifier.
[Payroll/SalaryLine/{id}](Route_DELETE_Payroll_SalaryLine__id__.md)|DELETE|Deletes the specified [SalaryLine](Type_SalaryLine.md) by its identifier.
