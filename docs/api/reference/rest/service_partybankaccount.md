
PartyBankAccount
================

Service to query [PartyBankAccount](Type_PartyBankAccount.md) independent of the [Customer](Type_Customer.md) , [Supplier](Type_Supplier.md) or [Employee](Type_Employee.md) objects.

**Base Url**: `https://api.poweroffice.net/PartyBankAccount/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[PartyBankAccount/](Route_GET_PartyBankAccount__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of party bank accounts filtered by odata query.
