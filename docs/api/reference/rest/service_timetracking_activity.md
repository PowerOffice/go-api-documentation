
Activity
================

Service to query, create and update [Activity](Type_Activity.md)

**Base Url**: `https://api.poweroffice.net/TimeTracking/Activity/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[TimeTracking/Activity/](Route_GET_TimeTracking_Activity__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [Activity](Type_Activity.md) filtered by odata query.
[TimeTracking/Activity/](Route_POST_TimeTracking_Activity_.md)|POST|Creates or updates the specified [Activity](Type_Activity.md) .
[TimeTracking/Activity/{id}](Route_GET_TimeTracking_Activity__id__.md)|GET|Gets the specified [Activity](Type_Activity.md) by its identifier.
[TimeTracking/Activity/{id}](Route_DELETE_TimeTracking_Activity__id__.md)|DELETE|Deletes the specified [Activity](Type_Activity.md) by its identifier.
