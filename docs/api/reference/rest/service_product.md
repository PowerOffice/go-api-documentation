
Product
================

Service to query, create and update [Product](Type_Product.md)

**Base Url**: `https://api.poweroffice.net/Product/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Product/](Route_GET_Product__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [Product](Type_Product.md) filtered by odata query.
[Product/](Route_POST_Product_.md)|POST|Creates or updates the specified [Product](Type_Product.md) .
[Product/{id}](Route_GET_Product__id__.md)|GET|Gets the specified [Product](Type_Product.md) by its identifier.
[Product/{id}](Route_DELETE_Product__id__.md)|DELETE|Deletes the specified [Product](Type_Product.md) by its identifier.
