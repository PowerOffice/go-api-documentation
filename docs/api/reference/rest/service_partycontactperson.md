
PartyContactPerson
================

Service to query [ContactPerson](Type_ContactPerson.md) independent of the [Customer](Type_Customer.md) or [Supplier](Type_Supplier.md) objects.

**Base Url**: `https://api.poweroffice.net/PartyContactPerson/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[PartyContactPerson/](Route_GET_PartyContactPerson__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of [ContactPerson](Type_ContactPerson.md) filtered by odata query.
