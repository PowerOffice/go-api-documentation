
ContactGroup (ContactGroup)
================



### Properties
Name | Type | Description
:----|:-----|:-----------
Id|number|Gets the identifier. This identifier is unique and assigned by PowerOffice Go when a new entity is saved, and should be provided when an entity should be edited.     If this identifier is not provided, PowerOffice Go will try to create a new entity.
SendInvoicesToGroup|boolean|Gets or sets a value indicating whether it is allowed to send a group invoice to the [Customer](Type_Customer.md) in the group.
Title|string|Gets or sets the title of the contact group. This title is unique per client (ignore case).
