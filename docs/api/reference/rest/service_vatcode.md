
VatCode
================

Service to query [VatCode](Type_VatCode.md)

**Base Url**: `https://api.poweroffice.net/VatCode/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[VatCode/](Route_GET_VatCode__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of vat codes filtered by odata query.
[VatCode/{id}](Route_GET_VatCode__id__.md)|GET|Gets the specified VatCode by it's id.
[VatCode/chartofaccount/{accountCode}](Route_GET_VatCode_chartofaccount__accountCode__options__options_.md)?options=&lt;options&gt;|GET|Gets available VAT codes for the specified general ledger account code.
