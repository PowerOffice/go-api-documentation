
CustomDimensionValue
================

Service to query, create and update [CustomDimensionValue](Type_CustomDimensionValue.md)

**Base Url**: `https://api.poweroffice.net/CustomDimensionValue/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[CustomDimensionValue/](Route_GET_CustomDimensionValue__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of customDimensionValues filtered by odata query.
[CustomDimensionValue/](Route_POST_CustomDimensionValue_.md)|POST|Creates or updates the specified customDimensionValue.
[CustomDimensionValue/{id}](Route_GET_CustomDimensionValue__id__.md)|GET|Gets the specified customDimensionValue by it's id.
[CustomDimensionValue/{id}](Route_DELETE_CustomDimensionValue__id__.md)|DELETE|Deletes the specified customDimensionValue by it's id.
