
ClientIntegrationInformation (ClientIntegrationInformation)
================



### Properties
Name | Type | Description
:----|:-----|:-----------
ActiveClientSubscriptions|string[]|All active Go-subscriptions for the client. Available subscriptions: Accounting (Regnskap og faktura), TimeTracking (Timeregistrering), Payroll, TravelExpense (Reiseregning), AccountingMicro (Regnskap Mikro), Quality, HolidayAndLeave, CustomerCheck (kundesjekk.no), AccountingNano (Regnskap og faktura), YearEndSoleProprietorship (Skattemelding ENK)
ClientId|string|Id of the client.
ClientName|string|Name of the client.
InvalidPrivileges|string[]|All invalid privileges for the integration based on the active Go-subscriptions for the client.
UserId|string|Id of the integration user.
ValidPrivileges|string[]|All valid privileges for the integration based on the active Go-subscriptions for the client.
