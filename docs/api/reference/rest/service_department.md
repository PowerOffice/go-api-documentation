
Department
================

Service to query, create and update [Department](Type_Department.md)

**Base Url**: `https://api.poweroffice.net/Department/`


### Routes
 Route | Method | Description
:------|:-------|:------------
[Department/](Route_GET_Department__options__options_.md)?options=&lt;options&gt;|GET|Gets a list of departments filtered by odata query.
[Department/](Route_POST_Department_.md)|POST|Creates or updates the specified department.
[Department/{id}](Route_GET_Department__id__.md)|GET|Gets the specified department by it's id.
[Department/{id}](Route_DELETE_Department__id__.md)|DELETE|Deletes the specified department by it's id.
