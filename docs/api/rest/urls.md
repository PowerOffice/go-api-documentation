REST - URL's
=================================

The URL's vary based on which PowerOffice Go environment you are targeting.

Please read more about the environments in [Registration and Client activation.](/Common/Registration.md)

In the documentation we will refer to the production URL's, so you will have 
to change them to the ones for the Demo environment if you are targeting that environment.

### Environments

Function | Base Url | Example
:--------|:----|:-------
Demo | https://api-demo.poweroffice.net/ | https://api-demo.poweroffice.net/customer/61
Production | https://api.poweroffice.net/ | https://api.poweroffice.net/customer/61
